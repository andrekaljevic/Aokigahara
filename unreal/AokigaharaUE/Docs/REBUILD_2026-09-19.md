## Non-negotiable evidence rules

1. The preserved point clouds declare no CRS in-file. Assign **EPSG:6676, JGD2011 / Japan Plane
   Rectangular CS VIII** explicitly during preprocessing. Its Transverse Mercator parameters are:
   latitude of origin 36°, central meridian 138.5°, scale 0.9999, false easting/northing 0.
2. Do not infer LAS X/Y semantics from variable names alone. EPSG's formal axes are northing/easting,
   while common GIS libraries expose easting/northing. Validate the stored axes against `mmstrj.zip`
   before locking the world transform.
3. MMS RGB is 8-bit in the low byte. Do not `>> 8` it.
4. Airborne LAS RGB is effectively an orthophoto drape, not independent under-canopy colour truth.
   Use MMS RGB for measured near-ground colour where coverage exists.
5. Missing terrain measurements remain missing. The rebuild pipeline emits NaN + observation counts;
   interpolation must be a named later step with its own provenance class.
6. Do **not** recreate `lava_skin_field.py` as a source of terrain truth. The project had been inventing
   pahoehoe lobes/ridges while Yamanashi's 0.5 m bare-earth relief already measured those forms.
7. The 960×720 web reference images may guide broad tone/composition only. They are not evidence for
   centimetre-scale bark, moss, roots or lava microgeometry.

## What this first rebuild commit restores

- `Scripts/jprcs8.py`: explicit EPSG:6676 WGS84 conversion wrapper, with axis naming that prevents the
  old northing/easting ambiguity.
- `Scripts/real_terrain_lib.py`: source validation, zipped LAS loading, classification inspection and
  measured-only rasterisation.
- `Scripts/build_real_terrain.py`: inspect the real airborne sheet and build a **specified** validation
  crop into 0.5 m DEM/DSM/CHM. It refuses to guess the crop.
- `Scripts/test_measured_rebuild.py`: EPSG fixture + raster orientation/nodata tests.

The existing `aokigahara_geo.py`, `test_geo.py`, `export_heightmaps.py` and UE importers on the base
commit remain untouched.

## First run on the Mac

```bash
cd /Applications/Aokigahara/unreal/AokigaharaUE
python3 -m pip install -r Scripts/requirements-measured.txt
python3 Scripts/test_measured_rebuild.py
python3 Scripts/build_real_terrain.py --inspect-only
```

Only after the LAS bounds/classification and MMS trajectory agree should a small validation crop be
chosen. Then run, for example:

```bash
python3 Scripts/build_real_terrain.py \
  --bounds XMIN YMIN XMAX YMAX \
  --resolution 0.5 \
  --out ImportData/measured_validation_0p5m.npz
```

The crop coordinates are intentionally not guessed in this commit.
